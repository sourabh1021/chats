# 📱 WhatsApp Clone (Node.js + Express + MongoDB)

## 📝 Description
This is a simple **WhatsApp-like chat application** built with **Node.js**, **Express**, **MongoDB (Mongoose)**, and **EJS templates**.  
Users can **create, read, update, and delete chats**, similar to a mini chat system.  

It demonstrates **CRUD operations** and dynamic rendering using **EJS**, along with **method-override** for PATCH and DELETE routes.

---

## ✨ Features
- 🟢 Create new chat messages  
- 👀 View all chat messages in a styled interface  
- ✏️ Edit existing messages  
- ❌ Delete messages  
- ⏰ Timestamp each message (`created_at`)  

---

## 🛠 Tech Stack
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (via Mongoose)  
- **Frontend:** HTML, CSS, EJS templating  
- **Other Packages:**  
  - `method-override` (for PATCH/DELETE)  
  - `express`  
  - `mongoose`
